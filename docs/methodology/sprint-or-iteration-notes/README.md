# Sprint or Iteration Notes

This folder contains the planning, progress, review, and retrospective notes for every SariwaBa sprint.

## Planned Sprints

- Sprint 0 – Project foundation
- Sprint 1 – Authentication and user foundation
- Sprint 2 – Initial classification workflow
- Sprint 3 – ML and history integration
- Sprint 4 – Quality and interface improvement
- Sprint 5 – Deployment and acceptance

## Sprint Note Template

Create one file for every sprint, such as `sprint-1.md`.

### Sprint Goal

State the measurable goal of the sprint.

### Selected Backlog Items

- List the features and tasks selected for the sprint.
- Include their acceptance criteria.

### Completed Work

- List the completed and tested work.

### Incomplete Work

- State what was not completed and why.
- Explain whether it will return to the backlog.

### Risks or Blockers

- Record technical risks, delays, and unresolved dependencies.
