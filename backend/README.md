Mao ni ang atong working environment para sa backend

type cd backend sa terminal if gusto ka mag work on sa backend

after getting in the backend type this command:
.\.venv\Scripts\activate.bat to enter the virtual environment
then cd SariwaBa to enter the django

If you want to run the backend type this in command:
python manage.py runserver

If you haven't installed the tools or libraries type this command:
pip install -r requirements.txt
